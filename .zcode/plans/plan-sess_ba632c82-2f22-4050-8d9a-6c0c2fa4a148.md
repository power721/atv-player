# 实现计划:源健康度学习与调度(WebHTV 站点健康排序移植)

## Context

WebHTV 借鉴调查第 4 项。探索确认 atv-player 现状盲点:
- **换源候选纯下标盲选**(`player_window.py:4003 _next_source_after_failure`),失败记忆仅内存坐标集合(:1296)、不跨会话、不记成功;自动换源默认关(`playback_auto_switch_source_on_failure=False`)。
- **全局搜索**(`main_window.py:5009 _run_global_search_page`)全并发无调度,单源成败无任何记录;**Python 插件搜索无超时**——挂死会让"搜索中…"永不结束。
- 全库零健康/评分统计;JSON store、90 天清理、config 字段、菜单/设置页的惯用模式齐备(可照抄)。

用户已确认**全量**范围:播放线路健康+换源排序+搜索记录+超时看门狗+插件管理器色点。护栏对齐 WebHTV:学习与排序默认开、展示只读恒显、不动用户手动排序。

## 1. 新模块 `src/atv_player/source_health.py`(纯逻辑+store,仿 chapter_skip.py+danmaku/preferences.py)

- `SourceHealthRecord`:key + search_success/search_fail/search_empty、play_success/play_fail、last_search_cost_ms/last_search_count、last_play_fail_streak、last_error(截 120 字)、updated_at。
- `SourceHealthStore(path=None)`:`app_data_dir()/"source-health.json"`;RLock + 内存权威副本(load 一次,读时过滤 90 天未更新条目);`record_search(key, outcome, cost_ms, count, error)` / `record_play(key, outcome, error)` 即时原子写(NamedTemporaryFile+replace,抄 preferences._write_all);`purge_stale(now=None)` 可注入时间(抄 danmaku/cache.py 模式,app.py 启动 daemon thread 调用,仿 app.py:421)。
- 纯函数 `health_score(record)`:两阶段移植 WebHTV 公式——播放成败比 60×(s−f)/(s+f+4)(主导)+ 搜索成败比 24×(ss−sf−se/2)/(ss+sf+se+4)(空结果半失败)+ 结果丰富度 min(count,20)×0.6 − 延迟惩罚 min(cost_s,8) + 近期播放事件 ±18(连续失败≥3 且分<0 强制 BAD);状态 GOOD≥20 / BAD≤−20 / WARN / UNKNOWN 无样本。单测锁定阈值。
- `rank_candidates(entries, store)`:稳定排序——分 desc、无样本居中(score=0)、BAD 沉底、同分保持原下标序。
- key 派生:`playback_line_health_key(source_kind, source_key, route_label, drive_share_key, vod_id)`:spider→`plugin:{manifest_id}:route:{label}`;bilibili 等内置多线路→`builtin:{kind}:route:{label}`;网盘(browse/telegram/pansou/msub)→`drive:{share_key}`(缺省退 vod_id);其他→`builtin:{kind}`。搜索→`search:{definition.key}`。
- `run_search_with_health(controller, keyword, page, key, store, *, timeout_seconds=25, enabled=True)`:ThreadPoolExecutor(1)+future.result(timeout) 包装计时+记录+超时翻译(TimeoutError→timeout 失败记录后抛原语义异常)——**看门狗与记录全收在模块内,main_window 只替换一行调用**;本地源(smart/history/favorites/following)传 enabled=False 不走 executor。

## 2. 记录点

- **播放**(player_window):`_pending_play_health_key` 生命周期守卫——`_load_current_item` 起播时置当前线路 key(`_current_playback_health_key()` 帮助函数派生);首个失败信号(8 个失败汇聚处,集中在 `_show_failed_startup_state` 与 `_try_auto_switch_source_after_failure` 前,实现时核对 8 点补漏)记 play fail 一次;首帧成功(`_handle_video_picture_state_changed` 清失败集合处,:6094-6100)记 play success 一次;`_switch_active_source`/`open_session` 重置;DASH 提前结束例外路径不记(:14440 语义)。
- **搜索**(main_window `_run_global_search_page`):`controller.search_items` 调用替换为 `run_search_with_health`(门控 `source_health_learning_enabled`),success/empty/fail(带 count、cost、error 分类)。
